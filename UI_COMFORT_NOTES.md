# Android comfort refresh

Based on f91b209 (1.0.9), preserving the current playback and network code.

- Mint surfaces and clearer secondary text.
- Address focus is visible on its container.
- 48 dp close/find controls; accessible close labels.
- Tablets use a taller address field and 3 tab columns at sw600dp / 4 at sw840dp.

Validation: signed APK build passed; all XML parsed; incremental installation succeeded on SM-S931B and SM-X210 without clearing application data. Both devices were dozing, so visual inspection and touch interaction remain unverified. No website or GitHub publication was performed. Package version remains 1.0.9 for this local preview.
